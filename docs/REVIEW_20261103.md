# 点検メモ 2026-11-03（クロより）

## 1. この仕組みは何をするもの？（1枚まとめ）

**LUMOUS マニュアル図解メーカー**です。仕事のやり方を文章で書くと、AI（Groq か Gemini）が図入りのマニュアルにしてくれます。

| ファイル | やくわり |
|---|---|
| `index.html`（約2400行） | 画面とほぼ全部の動き。文章を AI に送る → 図（mermaid）つきのマニュアルができる → 保存・画像や動画の追加・リンク追加・HTMLでダウンロード。 |
| `server.js`（約240行） | 自分のパソコンで動く小さなサーバー（Node.js、ポート 3456）。画面を配る／保存データを `user-data.json` に書く／**書いたあと自動で git commit して GitHub に push する**／動画をフォルダに書き出す／ダウンロードHTMLを返す。 |
| `user-data.json` | 保存したマニュアル本体（約 270KB、画像入り）。バックアップ用。 |
| `last-download.html` | 最後にダウンロードしたHTMLの「確認用コピー」（**約 32MB**）。毎回上書きされ、git にも入っている。 |

流れ：ブラウザの `localStorage` にまず保存 → `/api/backup` でサーバーへ → `user-data.json` に書く（Dropbox のフォルダがあればそこにも）→ `git add -A` → commit → `git push origin master`。
動画はブラウザの IndexedDB に入り、`/export-videos` ページで `/home/ryota/lumous-manual-public/videos` に書き出せます。

README、package.json、試験はもともとありませんでした。メール・LINE・X・メルカリ等へ送るコードは**ありません**（外へ出るのは AI の API と、mermaid を読む CDN だけ）。今回、本番や外部サービスは何も動かしていません。

## 3. 今回直したこと

- #1 `server.js`：既定で `127.0.0.1` だけで待ち受け。
- #2 `server.js`：静的ファイルは「プロジェクトの中」かつ「`.` で始まらない」ものだけ。`?v=1` 付きURLも正しく扱う。
- #3 `server.js`：動画 id を英数字・`_`・`-`（100文字まで）に限定。
- 試験用に `server.js` を「読み込んでも勝手に動かない」形にし、動画フォルダを `LUMOUS_VIDEO_DIR` で変えられるようにした。
- `test/server.test.js` を追加（5件）。

## 4. 試験の結果

`node --test test/server.test.js`（Node v22）→ **5件中5件 成功**。
試験は `/api/backup`（git push する所）を**呼びません**。直す前のコードでの失敗確認はしていません（旧コードは読み込み方式が違うため）。`index.html` 側の動きはブラウザが要るので、今回は回していません。

## 5. 次の提案（提督の判断が要るもの）

1. **#4**：push に失敗したら画面に赤く出し、次の保存で「未 push の commit があれば push しなおす」ようにする。
2. **#5**：`git add user-data.json` だけにし、`last-download.html` は `.gitignore` へ（履歴の掃除は別相談）。
3. **#6**：ブランチ名を設定にする。
4. **#7・#12**：同期の失敗を画面に出す。
5. **#9**：mermaid の版を固定（例 `@10.9.x`）。
6. **#8**：Gemini はキーを URL でなくヘッダー `x-goog-api-key` で送る。
